# pandas-energy-analytics
A hands-on Pandas training project for data analysts in the energy sector. Covers core data manipulation skills—including DataFrame creation, real-world dataset analysis (electric power consumption &amp; e-commerce), missing value handling, and efficient data cleaning—using Python, Pandas, and NumPy. 

## Usage

To run the Jupyter notebooks in this repository, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/stkisengese/pandas-energy-analytics.git
    cd pandas-energy-analytics
    ```

2.  **Install dependencies:**
    It is recommended to use a virtual environment.
    ```bash
    pip install pandas numpy jupyter
    ```

3.  **Launch Jupyter Notebook:**
    ```bash
    jupyter notebook
    ```

    Your web browser will open with the Jupyter interface, where you can navigate to and run the `.ipynb` files.

## Exercises

*   **ex01_dataframes.ipynb:** Introduces the creation of Pandas DataFrames from various data structures, including NumPy arrays, Pandas Series, and dictionaries.
*   **ex02-electric-power.ipynb:** Analyzes household electric power consumption data. This notebook covers data loading, cleaning (dropping columns, handling missing values), and time-series analysis.
*   **ex03-ecommerce.ipynb:** Explores a dataset of e-commerce purchases. It includes calculating descriptive statistics, filtering data based on conditions, and analyzing customer behavior.
*   **ex04_handling_missing_values.ipynb:** Demonstrates techniques for handling missing data in the Iris dataset. It covers different imputation strategies and discusses the importance of data quality.
